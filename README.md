# Nostalgic Childhood Memory

Entry for the make.fun bounty **"Make the AI Judge Feel Nostalgic: A Childhood Memory"** — a program that writes one sentence recalling a childhood memory, the kind that brings back a summer evening in a grandmother's kitchen.

The sentence it writes:

> Every August evening my grandmother ladled rice straight from the steamer onto my plate, and the steam fogged my glasses so the whole kitchen went soft before I took the first bite.

## Run

Requires Node 22 or later. No dependencies, no network access.

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt`. To write elsewhere instead:

```sh
ENTRY_OUTPUT_PATH=/tmp/entry.txt node main.ts
```
